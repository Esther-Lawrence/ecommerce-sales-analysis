# E-Commerce Sales Analysis

# Project Overview

This project explores an e-commerce sales dataset to identify sales trends, product performance, revenue patterns, and opportunities for business improvement.

The project involves cleaning and preparing the dataset, analyzing sales information, and developing visualizations to communicate key findings.  

# Business Problem

E-commerce businesses generate large amounts of sales data, but identifying meaningful patterns and using them to make informed business decisions can be challenging.

Without proper data cleaning and analysis, businesses may struggle to understand product performance, revenue trends, and areas that require improvement.

Businesses need reliable sales data to understand which products perform well, how revenue changes over time, and where improvements may be needed.

This project aims to analyse e-commerce sales data to uncover useful insights that can help businesses evaluate performance, identify opportunities, and to turn a messy sales dataset into structured, meaningful information that supports data-driven decisions.

# Project Objectives

* Clean and prepare the dataset.
* Identify and handle missing, duplicate, and inconsistent records.
* Data type issues and other data quality problems.
* Validate data accuracy.
* Analyse sales performance
* Identify product and category trends.
* Explore customer and regional performance
* Answer business questions using SQL.
* Conduct python analysis.
* Develop visual reports and dashboards.
* Communicate findings and actionable recommendations.

# Data Source

This project uses an AI-generated synthetic e-commerce sales dataset created with the assistance of ChatGPT for educational and portfolio purposes.
 [Download the original dataset](https://github.com/Esther-Lawrence/ecommerce-sales-analysis/edit/main/README.md/ULTIMATE_MESSY_SALES_DATASET_10000_PLUS_ROWS (1).xlsx)
The dataset is used to practise data cleaning, SQL querying, Python analysis, and dashboard development. It does not represent verified transactions from a real company.
